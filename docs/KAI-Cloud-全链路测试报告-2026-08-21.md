### 7.2 自动成交和自动交付不属于当前通过范围

当前 `/api/ready` 显示 Agent delivery 与 metering 尚未就绪，Hosting V2 交易仍关闭。因此本报告通过的是“目录浏览 → 登录 → 人工询价 → 私有公钥 → 个人中心 → 管理员人工交付”链路，不是自动开机和自动计费链路。

### 7.3 HSTS 尚未启用

HTTPS、证书和 HTTP→HTTPS 跳转均正常，但响应中未启用 HSTS。建议在确认域名、证书续期和所有回调均长期稳定后单独启用并回归，不应与业务版本一起临时修改。

### 7.4 工作区存在未跟踪的独立项目

项目跟踪代码的 ESLint 检查通过。直接对整个物理目录运行 ESLint 会扫描未纳入当前 Git 提交的 `.local-workspaces/app`，该独立移动端工作区存在 48 个检查错误；它不在当前部署镜像和本次 531 项测试范围内。建议把独立工作区移出 Web 仓库或加入明确忽略规则，避免以后把非生产代码误算进 Cloud Web 质量门禁。
