# KAI Cloud “我的资产”与卡时计价产品方案 V1.0

> 本方案由产品经理制定，开发团队按本文执行。

## 核心口径

资源用卡时报价，订单用卡时结算，收益用卡时入账；人民币只负责给卡时账户充值。

- KAI Cloud 的交易计价资产只有 **KAI 标准卡时**。
- 市场、报价、合同、扣款、退款、租金、佣金和平台费全部只显示卡时。
- 人民币只允许出现在“我的资产 → 卡时充值”和财务后台。
- 用户可见卡时统一保留两位小数；内部可保留微卡时和秒级计量，最终权益记录必须形成可对账的两位小数结果。

## 我的资产

Canonical 路径为 `/member/assets`，旧 `/member#card-hours` 保持兼容并跳转至新页面。

页面只分四区：

1. **资产总览**：可用卡时、已锁定卡时、待结算收益、累计已入账收益。
2. **卡时明细**：时间、类型、业务编号、卡时变动、变动后余额。
3. **收益**：租金和佣金的待结算、已入账、费率版本。
4. **卡时充值**：用户前台唯一允许出现人民币的区域。

“我的回购”不进入 V1 主资产页，继续保持关闭。

## 人民币白名单

允许出现：

- `/member/assets#topup` 卡时充值区。
- 未来的充值确认、结果、订单、充值退款。
- `/admin/**` 的支付、财务、发票、对账和退款。
- 法定协议、发票、支付凭证和审计导出。

永久禁止：

- 首页、活动页、GPU 市场、Offer 详情、合同、实例和订单。
- Hosting 营销页、Supply 挂牌/订单/设备/收益、行情、资源页和需求提交。
- 文案“人民币/小时”“折合人民币”“人民币参考价”“网站人民币价”。

## 显示与结算

- 市场唯一报价格式：`31.14 卡时 / GPU 小时`。
- 公开 Offer 价格只返回 `assetCode` 和 `cardHourMicrosPerGpuHour`等卡时字段。
- 报价详情显示卡时单价、租期和预估锁定卡时。
- 合同显示锁定、实际扣减、退回、已结算，四者均为两位小数并与账本勾稽。
- 挂牌字段为“KAI 标准卡时 / GPU 小时”，最多两位小数。
- 租金、佣金、平台费和净收益全部为卡时。

## 充值关闭状态

当前支付和公开充值继续关闭。

- 页面显示“卡时充值暂未开放”。
- 说明为“支付通道、退款、发票与资金规则完成验收后开放。当前试运营卡时由平台审核发放。”
- 可显示“充值换算基准：1.00 KAI 标准卡时 = ¥1.002”。
- 金额输入、快捷金额和支付按钮必须隐藏或禁用。
- `POST /api/v1/member/card-hours/topups` 关闭时返回 `TOPUP_CLOSED` / 503，不创建 `PENDING` 付款单。

## 验收

1. 匿名用户从首页到 GPU Offer、登录、合同，全程只看到卡时价格。
2. 供应商从挂牌到订单、收益，全程只看到卡时金额。
3. 人民币只在“我的资产 → 卡时充值”和财务后台出现。
4. 充值关闭时无可操作支付按钮，不生成付款单。
5. 卡时统一两位小数，市场、合同和账本相互勾稽。
6. 公开 API 不返回 `cny*`、`currency: CNY` 或 `amountCents`。
7. Gateway、Host Agent、验真、并发预留和清理 fail-closed 回归继续通过。

## 回退原则

`KAI_MARKET_V1=0` 可回退旧路由，但“人民币每小时报价禁止出现”是永久产品政策，不随功能开关回退。
