## 六、必须执行的失败测试

- ☐ 错误 Agent 签名被拒绝
- ☐ 过期或重复心跳被拒绝
- ☐ 错误 Gateway ticket 被拒绝
- ☐ 已过期租约不能连接
- ☐ 撤销租约立即断开
- ☐ 买家错误 SSH 私钥不能登录
- ☐ Agent 离线时订单不得进入“可连接”
- ☐ GPU UUID 改变后挂牌自动暂停
- ☐ 开通失败自动释放卡时并进入清理
- ☐ 清理失败进入 `DRAINING`，不得自动再售
- ☐ 重复回调、重复停止、重复退款保持幂等
