# KAI Cloud 产品页面职责（P0 收口）

本文件记录 2026-08 的安全收口边界。代码唯一事实源为
`lib/product-surface-policy.ts`。

| 路径 | 唯一职责 | 是否成交 |
| --- | --- | --- |
| `/buy` | 登录后的统一购买工作台，读取就绪状态、卡时余额和真实报价 | 将真实 GPU 报价交给 `/gpu/offers/[offerId]` |
| `/gpu` | 经过验真的实时 GPU 报价、详情和合同 | 是，使用 Hosting V2 报价与合同 |
| `/resources` | GPU、模型和基础设施参考目录 | 否，只询价，不承诺即时库存 |
| `/market` | 卡时、GPU、模型和基础设施价格行情 | 否，只读 |
| `/supply` | Hosting V2 供应商控制台 | 供应侧唯一生产入口 |

## 金额边界

- 算力报价、合同、计量和供应商收益只使用 KAI 标准卡时，不显示人民币每小时价格。
- 人民币支付只属于“我的资产 → 充值卡时”，入口为 `/member#card-hours`；
  市场、资源目录和供应商控制台不得把人民币参考价带入交易报价。

## 兼容入口

- `/market/listings` 临时跳转 `/buy`，避免出现第二个交易市场。
- `/supply/resources` 及其 `new`、`[deviceId]` 子路由永久跳转到
  `/supply/devices` 对应页面，旧书签继续可用。
- 旧 Supply 组件保留在原位置作为回退参考，但不得从 App Router 挂载。
  明细由 `LEGACY_UNROUTED_SUPPLY_MODULES` 管理并由测试守护。

## 回退

本次改造没有删除文件、没有数据库迁移、没有改变成交数据。需要回退时，
恢复四个兼容路由原有的字面重定向即可；页面、订单和审计数据不受影响。
