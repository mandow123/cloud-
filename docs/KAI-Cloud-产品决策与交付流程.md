# KAI Cloud 产品决策与交付流程

## 固定流程

1. 需求接收人将用户原话完整转述给产品经理，不擅自改写产品目标。
2. 只由产品经理输出产品方案，包括信息架构、用户流程、业务边界、数据口径、验收标准和回退策略。
3. 开发团队只执行已批准方案；前端、API、账本、测试和运维可并行实施，但不得各自发明产品口径。
4. 主协调人负责跨端整合、冲突处理、全量构建、闭环验收和风险报告。
5. 没有产品方案不开工；前后端未联合验收不宣称完成；未经明确授权不上线、不推送。

## 每次交付必须包含

- 产品经理批准的方案文档。
- 方案到页面、API、数据和测试的对应关系。
- 真实数据、历史参考、模拟验收与可成交库存的明确区分。
- 全量类型检查、生产构建、自动化测试和回退检查结果。
- 尚未具备的生产条件和 fail-closed 状态，不用模拟结果代替。
