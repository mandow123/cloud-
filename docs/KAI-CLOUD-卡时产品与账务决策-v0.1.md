# KAI Cloud 卡时产品与账务决策 v0.1

更新日期：2026-08-10

## 1. 定位

卡时（账务资产代码 `KAI_CREDIT_HOUR`）是 KAI Cloud 内部用于购买平台资源的预付使用额度，不是 GPU 物理卡时，也不是 KAI-SCH 行情指数。人民币只用于购买卡时；资源正式订单只通过卡时结算。

固定购买价为 `1 卡时 = ¥1.002`。账本按百万分之一卡时记账。为避免人民币“分”的舍入误差，充值数量限定为 5 卡时的整数倍，因此 5 卡时正好支付 ¥5.01。

## 2. 已实现边界

- 交易主体拥有独立卡时钱包，不与个人展示资料或匿名市场会话混用。
- 支付宝只作为人民币购买卡时的入金通道；浏览器返回页面不入账，只有服务端验签成功的异步通知才能入账。
- 资源订单先绑定卡时支付单，再原子扣减钱包；余额不足不扣款，可充值后用同一订单重试。
- 充值、消费使用不可修改的双分录账本，并带业务唯一键和幂等控制。
- 邀请关系仅允许一级、每个受邀交易主体只绑定一次、禁止自邀。
- 当前佣金按订单卡时金额的 3% 生成“待生效”记录，仅作为首版建议；不会直接变成可用余额。

## 3. 个人中心信息架构

个人中心集中展示：可用卡时、冻结卡时、累计购买、累计消费、购买记录、卡时明细、我的对比、我的回购、租金收益、佣金收益和邀请奖励。表格金额右对齐并使用等宽数字；状态不能只靠颜色表达；输入与按钮采用 KAI UI 的零圆角和语义色。

## 4. 暂不自动开放

### 回购

在回购价、手续费、单日限额、身份核验、反洗钱、人民币出款审核和资金准备金规则确认前，不提供回购提交接口。面板只展示记录位。未来流程应为：锁定卡时 → 审核 → 出款 → 最终扣减；失败则解锁，不能直接按购买价承诺兑付。

### 收益生效

租金与佣金目前区分“待结算/待生效”和“可用”。佣金需等关联订单完成、验收并过退款观察期后再归属；退款必须生成冲销记录。租金需要由真实结算事件写入，测试结算不得形成可用卡时。

## 5. 上线前必须确认

1. 佣金比例是否采用首版建议的 3%，以及奖励上限、观察期和作弊处理规则。
2. 租金由哪类真实结算事件触发，以及平台服务费和税务口径。
3. 卡时退款、过期、账户注销和余额处置规则。
4. 回购是否开放；若开放，先完成专项法务、财税、支付合规和资金风险评审。
5. 支付宝生产商户参数、回调域名和资金对账流程。

## 6. 管理员入口

管理员后台只保留独立账号密码入口。飞书管理员登录、管理员邮箱入口和首次公开抢占 Root 的入口均已移除。普通用户通过 `account.kai.com` 完成邮箱注册、验证和登录，Cloud 使用 OIDC 建立普通个人会话且不授予管理员角色。
